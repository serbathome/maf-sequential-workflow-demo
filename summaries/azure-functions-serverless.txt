Azure Functions ist Microsoft Azures serverloser, ereignisgesteuerter Compute-Dienst. Entwickler schreiben fokussierte Funktionen in Sprachen wie C#, Java, JavaScript, TypeScript, Python, PowerShell oder Go, waehrend Azure die Laufzeitinfrastruktur und Skalierung verwaltet. Ausloeser starten jede Funktion als Antwort auf HTTP-Anfragen, Zeitplaene, Nachrichten, Datei-Uploads oder Datenbankaenderungen, waehrend Ein- und Ausgabebindungen vereinfachte Verbindungen zu anderen Azure-Diensten bereitstellen.

Der Dienst unterstuetzt skalierbare APIs, zeitgesteuerte Aufgaben, Datenstromverarbeitung, Nachrichtensysteme, Datei-Workflows und innovative KI-Integrationen. Die Erweiterung Durable Functions ermoeglicht zuverlaessige, zustandsbehaftete Workflows durch Verwaltung von Checkpoints, Wiederholungen, Wiederherstellung und langlaufenden Orchestrierungen. Anwendungen koennen lokal entwickelt, ueber IDEs, Befehlszeilentools oder CI/CD-Pipelines bereitgestellt und mit Azure Monitor und Application Insights ueberwacht werden.

Hosting-Optionen umfassen den empfohlenen Flex Consumption-Plan, den Premium-Plan, dedizierte App Service-Plaene und Azure Container Apps. Die Auswahl beeinflusst Abrechnung, Skalierung, Netzwerkanbindung, Container-Support und Startverzoegerung. Fuer sichere Bereitstellungen koennen Teams verwaltete Identitaeten, Azure Key Vault, HTTPS, API Management, private Endpunkte, rollenbasierte Zugriffssteuerung und mehrschichtige Ueberwachung nutzen.
